# HealthTrail Hospital — UK GDPR & EHR Access Controls Assessment

**IT Audit & GRC portfolio | Healthcare data protection | November 2026**

## Overview
This assessment examines how HealthTrail Hospital manages access to Electronic Health Records (EHR), particularly for billing and administrative staff. It evaluates whether users have appropriate permissions, whether access is updated after role changes, and whether management regularly reviews access rights.

The work is framed around **UK GDPR**, the **Data Protection Act 2018**, and relevant patient confidentiality principles. It is a scenario-based portfolio assessment, not a live hospital audit.

## Scope and approach
- Evaluate **role-based access control (RBAC)** and least privilege for non-clinical users.
- Review **mover access management** when employees change departments.
- Assess the design of **periodic access recertification** and exception follow-up.
- Map access risks to **UK GDPR Articles 5, 6, 9 and 32**.
- Develop a **Risk and Control Matrix (RCM)**, evidence requests, proposed audit tests and remediation criteria.

## Key findings

| Finding | Risk | Recommended action |
| --- | --- | --- |
| Excessive clinical access for non-clinical roles | Unnecessary exposure of sensitive health data | Approved role-permission matrix and enforced RBAC |
| Old permissions retained after staff transfers | Accumulation of inappropriate access | HR-triggered access changes with verified removal |
| Inconsistent periodic access reviews | Access exceptions may persist undetected | Complete recertification, sign-off and exception closure |

**Risk priorities are provisional.** The supplied scenario supports the concerns, but actual user populations, logs and access records were not independently tested.
